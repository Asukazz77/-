# 豆苗实验室

面向 6–12 岁孩子的少儿 AI 与计算机科普互动网页。三个实验，一个接一个过关，一屏一个。

| 实验 | 孩子要做的 | 讲的是 |
|---|---|---|
| 01 开关就是数字 | 四个开关，凑出 3、15、12、9 | 二进制、位权、每往左翻一倍 |
| 02 AI 是怎么认出猫的 | 勾四个特征看置信度，再答四道判断题 | 特征、置信度、AI 的局限 |
| 03 这封信能信吗 | 判断五封信，三假两真 | 陌生链接、要密码、要钱 |

封面改过一版。最早打开只有一株豆苗，看不出这是个讲计算机的页面，后来换成一台会笑的电脑，豆苗从机顶长出来。

## 几条规矩

**顺序解锁。** 实验二要做完实验一才开，实验三要做完实验二，毕业证要三个全做完。点没解锁的目录不跳页，底部弹一条提示，说还差哪一步。

**答错能重来。** 判断题和信件选错，就地标红「再想想」，不扣分，也不锁死，选到对为止。

**没做完不放行。**「下一个」是灰的，旁边写着还差几步。

**「你发现了」在完成前藏着。** 第一版是敞着的，孩子往下滚一眼看到结论，实验就白做了。现在藏到做完那一刻。

凑中一关，约 1 秒后四个开关自己全灭，从 0 开始下一关。四关全过时不灭，停在最后那个数上。

## 二进制怎么讲

第一版是八个开关，位权 128 到 1，要凑 13、100、255。让 6 岁的孩子口算 128+64，他算不出来，只能一个个试——那就是猜数字，不是二进制。

现在给四位：8、4、2、1。扳手指头够用，翻倍关系一眼看得出来。

每个开关自上而下三行：当前是 0 还是 1、灯泡亮不亮、这一位的位权。开关下面是实时算式，`1×8 + 0×4 + 1×2 + 1×1 = 11`，亮着的那一位变蓝。加的过程摊开写，不用他猜。

四关是 3 → 15 → 12 → 9。3 只能点亮两个（1+2）；15 是四个全开；12 是 8+4；9 是 8+1，中间两位可以不要。

## 那只会走的小豆苗

页面上常驻一只小豆苗，按住能拖到任何地方。它也闲不住：每 5–9.5 秒做一件事——横着挪一小段、蹦一下、左右张望，或者嘀咕一句，不用点它也会冒出来。

点它算摸它，会蹦一下，同时弹出气泡：

- **给我个提示**：按你当前在哪一页、还差几步，说具体的话
- **随便聊聊**：随机一句关于 0 和 1、AI、安全的小知识

气泡开着的时候再点它，只摸，不关。关掉靠 ×、点外面、或者 Esc。

它和封面是同一台电脑：屏幕上有眼睛和笑嘴，机顶两片叶子。进站时先出来打个招呼，停两秒，再用 0.95 秒缩进右下角，就待在那儿了。做完一个实验它会蹦一下。

静置 12 秒没动静，它才从旁边冒出「摸摸我」，点一下就收。页面滚动时它淡到 34%，停下来 0.65 秒亮回来。打印时它不出现。

## 怎么打开

双击 `index.html`。

不用装东西，不用开命令行，不用联网。整个站三个文件，不引用外部资源。

## 部署成网站

纯静态，直接传。

要传的只有 `index.html`、`css/`、`js/` 三样，`docs/` 和测试目录不用带。

已验证放在子路径下（比如 `用户名.github.io/仓库名/`）也正常，代码里没有绝对路径。

| 方式 | 怎么做 | 适合 |
|---|---|---|
| **GitHub Pages** | 新建仓库 → 传上那三样 → Settings → Pages → Source 选 `main` 分支根目录 → 等一分钟 | 评委要链接，最通用 |
| **Gitee Pages** | 同上，仓库设为公开 → 服务 → Gitee Pages → 部署 | 国内访问快，但要实名 |
| **Netlify / Vercel** | 把三样拖进网页的部署区，拖完就有网址 | 最快，不用注册仓库 |

部署完地址形如 `https://你的用户名.github.io/doumiao-lab/`，手机电脑都能开。

注意：`css/main.css` 和 `js/main.js` 是相对路径，三个东西得保持现在的目录关系。把 `index.html` 单独拎出来传，样式会掉。

只想拿一个文件走，用 `豆苗实验室_单文件版.html`，样式、脚本、插画全在这一个文件里，微信、QQ 直接发它也行。

## 技术说明

没有构建步骤，改完保存、刷新就生效。

没有 npm 包、没有框架、没有图标库，也不引 CDN。断网、校内网受限、评审机不联网，都能完整跑。

没有图片文件，所有插画都是内联 SVG，不会 404。

### 动态美术

封面分层落位：显示器、键盘、支架依次出现，豆苗画出来再轻摇。灯泡一呼一吸，眼睛偶尔眨，两颗 0/1 在背景里浮着。

开关的数字会跳，换关时目标条弹进来，过关的勾像盖章一样落下。猫尾巴一直摆，勾耳朵时耳朵抖一下。实验二那行大字先停一下、再涨一点、最后收回。证书印章斜着敲下来。

只动 `transform` 和 `opacity`，`prefers-reduced-motion` 打开时全部停。

### 无障碍

- 正文字号下限 17px，对比度 ≥ 4.5:1
- 键盘能走完全程，`:focus-visible` 不抹掉
- 触控目标 ≥ 44×44，有「跳到正文」链接
- 算式和目标条带 `aria-live`，只在换关换值时写 DOM，读屏不会反复播报
- 关掉 JavaScript，页面还是按顺序铺开，只是不能打分

### 一个字体上的取舍

数字用 Segoe UI，没用 Consolas。Consolas 的 `0` 中间带一撇斜杠，孩子会把它看成空集符号。
